# Cart2Insights: Decoding E-Commerce Performance

## Project Overview
Cart2Insights is an e-commerce data analytics project that analyzes order performance, product revenue, delivery efficiency, and customer satisfaction using Python, SQL, and Streamlit.

## Objectives
- Analyze order volume and order status.
- Identify high-revenue product categories.
- Examine monthly revenue trends and payment methods.
- Evaluate delivery performance and customer review scores.
- Present actionable business insights in an interactive dashboard.

## Tools and Technologies
- Python
- Pandas
- SQL and MySQL
- Matplotlib
- Streamlit
- Jupyter Notebook

## Key Findings
- **Total orders:** 99,441
- **Delivered orders:** 96,478
- **Product item revenue:** 13,591,643.70
- **Late-delivery rate:** 8.11%
- **Repeat-customer rate:** 3.12%
- **Average review score:** 4.09 / 5

On-time deliveries received an average review score of 4.29/5, compared with 2.57/5 for late deliveries.

## Dashboard Features
- KPI cards
- Monthly revenue trend
- Order status distribution
- Top 10 product categories
- Customer review analysis
- Delivery performance analysis
- Business insights and recommendations

## Run Locally

1. Clone this repository.
2. Install the dependencies:
   `pip install -r requirements.txt`
3. Run the dashboard:
   `streamlit run app.py`
